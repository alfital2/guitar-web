# Pedal typography redesign — report

**Problem solved:** "some fonts on the effects are hard to read and mostly not
unique nor matching the effects style and vibes." Fixed by (a) moving personality
to the pedal NAME with a per-effect font + treatment, (b) putting ALL knob labels
on one clean condensed sans, and (c) deriving a directional engraved ink so no
name melts into its body (kills the old gold-on-gold PING-PONG case).

## Design system

- **Knob labels — one font everywhere:** `Barlow Condensed` 600, 8px,
  letter-spacing .08em, UPPERCASE. No decorative fonts at 8px anywhere. Ink +
  halo follow the pedal body (light on dark, dark on bright).
- **Name — the branding element (10–17px):** one personality family per sonic
  family, differentiated per-pedal via size / tracking / skew / case + an
  engraved emboss shadow. Script faces (Pacifico) keep mixed case.
- **Contrast floor ≥ 4.5:1:** ink direction derives from body luminance; the
  wordmark renders on the faceplate's shaded lower band with a soft directional
  "ink-well" scrim behind it. Contrast is measured against that real surface
  (`nameSurface()` in fx-art.js) — not the flat identity color.
- **Font budget = 10 families (was 9), one `<link>`, `font-display: swap`:**
  Inter, JetBrains Mono, Pacifico (kept — amp logo), Barlow Condensed, Oswald,
  Audiowide, Orbitron, Bungee, Righteous, Anton. Removed the hard-to-read
  Bungee Inline, Special Elite, Major Mono Display.
