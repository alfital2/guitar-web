## What was built

1. **Rig bar** (`rig-bar.js` + `body.rig-docked` CSS): both panels collapsed →
   `.window-main` becomes a grid whose last row holds both strips side by side
   (amp capped at `fit-content(62%)`, scrolls internally; board strip keeps a
   readable share). 90px row measured. Either panel expanding un-docks.
   Collapse states persist via the existing chainStore keys. NOTE learned:
   `fit-content()` is INVALID inside `minmax()` — the whole declaration is
   dropped silently; it must be a bare track size.
2. **Auto-fold on transport** (`auto-fold.js` + main.js): fold on record click
   (covers count-in) and play start; restore at record stop, play pause,
   natural end, skip, seek and power-off — all through `restoreFoldIfIdle()`
   so a seek/skip never unfolds mid-recording. Fold goes through new silent
   `amp-set-collapsed`/`board-set-collapsed` events (same internal path as the
   UI controls, incl. the amp strip value sync) — no re-render, no audio-graph
   rebuild. Persistence only on restore, so storage always matches the user's
   real preference; a panel the user had collapsed manually stays collapsed.
3. **Unified collapse affordance**: one `.collapse-chev` style shared by the
   amp chevron, board chevron and `pb-collapse`; all carry `aria-expanded`;
   both strips are `role=button` + `tabindex=0` + Enter/Space expand + visible
   focus ring; both strips say "TAP TO EDIT"; `presets-toggle` reflects
   `aria-expanded` for the sidebar. No panel redesigns.
4. **Power-on ritual**: `start()` success → `#amp.power-warmup` (one-shot tube
   opacity ramp / strip sheen when collapsed) then `.power-lit` connectors
   staggered left→right via `--lit-delay`, settle, classes removed once.
   ≤2s, opacity/color keyframes only, skipped under reduced-motion (JS check +
   CSS belt-and-braces).
5. **Compressor viz punch-up** (`fx-viz.js`, compressor only — limiter keeps
   the shared kneeViz): same true knee math; program level now pumps ±16dB at
   ~0.7Hz against the knee; bold width-scaled IN/OUT meters with peak caps
   (gap = gain reduction); GR needle gauge that kicks with each pump; GR strip
   along the top edge; probe + trail + halo riding the knee. Parked = static
   pose (kick/decay clock unchanged).
